# 상태 요약 / 업데이트 스킬

이 저장소의 공유 상태판 `status.md`를 다루는 스킬이다.
"Computer task status check" 채팅(확인/보고 센터)에서 명령을 받으면 실행한다.

## 동작

명령을 받으면 아래 순서로 처리한다.

### 1) 최신 상태 끌어오기 (항상 먼저)

다른 작업 채팅이 원격 저장소에 기록을 남겼을 수 있으므로, 요약 전에 원격을 먼저 반영한다.

```bash
git fetch origin claude/computer-task-status-3c94vl -q
git checkout origin/claude/computer-task-status-3c94vl -- status.md
```

### 2) 새 기록 추가 (사용자가 기록 내용을 준 경우에만)

사용자가 "○○ 완료로 기록해줘"처럼 추가할 내용을 준 경우에만 수행한다.
`status.md`의 표 맨 위(헤더 구분선 바로 아래)에 한 줄 추가한다.

형식: `| 시각(UTC) | 채팅항목 이름 | 상태 | 내용 |`
- 시각은 UTC 기준 `YYYY-MM-DD HH:MM`
- 상태: ✅완료 / ⏳진행중 / ❓질문대기 / ⚠️오류

추가했으면 커밋 후 지정 브랜치로 푸시한다.

```bash
git add status.md
git commit -m "status: <채팅항목 이름> <상태> 기록"
git push -u origin claude/computer-task-status-3c94vl
```

푸시 실패가 네트워크 오류면 2s → 4s → 8s → 16s 백오프로 최대 4회 재시도한다.

### 3) 요약 보고 (항상 마지막)

`status.md`의 기록 표를 읽어 짧게 요약해 보고한다.

- 표를 그대로 보여주되, 최신 항목이 위로 오게 한다.
- 상태별 건수를 한 줄로 요약한다. 예: "완료 2건 · 진행중 1건 · 질문대기 0건 · 오류 0건".
- ❓질문대기 / ⚠️오류 항목이 있으면 눈에 띄게 먼저 짚어준다.
- 아직 기록이 없는 좌측 작업 채팅이 있으면, "그 채팅이 이 저장소에서 작업하며 상태를 남기면 자동으로 잡힌다"고 한 줄 덧붙인다.

## 주의

- 채팅 세션끼리는 격리되어 다른 채팅의 대화 내용을 직접 읽을 수 없다.
  상태 공유는 오직 `status.md` 파일을 통해서만 이뤄진다.
- 사용자가 손으로 기록할 필요는 없다. 각 작업 채팅의 Claude가 자동으로 기록하며,
  이 스킬은 그 기록을 모아 요약하는 역할이다.
