# 카카오톡 PC 자동 전달 (AutoForward)

받은 카카오톡 메시지(**텍스트 · 이미지 · 파일**)를 지정한 **한 사람**에게 그대로
전달합니다. **오픈채팅은 제외**합니다.

- 방식: "복사→붙여넣기"가 아니라 **카카오톡 내장 "전달" 기능**을 자동으로 눌러줍니다.
  → 그래서 이미지·파일도 원본 그대로 넘어갑니다.
- 실행 도구: **AutoHotkey v2** (무료, Windows 전용)

---

## ⚠️ 먼저 알아둘 점 (꼭 읽어주세요)

1. **이건 UI 자동화입니다.** 카카오톡에는 개인 계정용 "자동 전달" 공식 기능/API가
   없어서, 마우스·키보드를 대신 움직여 카톡 화면을 조작하는 방식입니다.
   → 카카오톡 **버전 · 화면 해상도 · 테마(라이트/다크)** 가 바뀌면 좌표가 어긋나
   동작이 깨질 수 있습니다. 그래서 **한 번 보정(캘리브레이션)** 이 필요합니다.
2. **약관/계정 위험.** 매크로·자동화는 카카오톡 이용약관에서 제한될 수 있어
   계정 이용 제한 가능성이 있습니다. **본인 책임 하에** 사용하세요.
3. **프라이버시.** 남이 보낸 메시지·사진·파일을 제3자에게 자동 전달하는 것이므로,
   전달받는 사람과 원 발신자 모두에 대한 **동의/주의**가 필요합니다.
4. 완전 자동(`auto`)은 실험적입니다. **먼저 `hotkey` 모드로 보정**한 뒤 넘어가세요.

---

## 1. 설치

1. AutoHotkey **v2** 설치 → https://www.autohotkey.com/ (v1 아님, v2여야 함)
2. 이 폴더의 `AutoForward.ahk` 를 본인 PC로 복사.
3. 카카오톡 PC를 실행하고 로그인.

---

## 2. 설정 (스크립트 상단 CONFIG)

`AutoForward.ahk` 를 메모장/편집기로 열고 위쪽 `CFG := { ... }` 부분을 수정합니다.

| 항목 | 설명 |
|---|---|
| `TargetName` | **필수.** 전달받을 사람의 카톡 이름. (전달 대화상자 검색에 쓰임) |
| `Mode` | `"hotkey"`(수동 단축키) 또는 `"auto"`(자동). 처음엔 `hotkey`. |
| `ForwardHotkey` | 지금 전달 단축키. 기본 `Ctrl+Alt+F`. |
| `ToggleHotkey` | 자동 On/Off 토글. 기본 `Ctrl+Alt+A`. |
| `QuitHotkey` | 종료. 기본 `Ctrl+Alt+Q`. |
| `ExcludeTitlePatterns` | 이 문구가 제목에 있으면 전달 안 함(오픈채팅 등). |
| `MsgOffsetX/Y` 등 | 좌표 보정값 (아래 3장 참고). |

---

## 3. 보정 (캘리브레이션) — 제일 중요

카카오톡 창 위치·버튼 위치가 사람마다 달라서, 아래 값을 본인 화면에 맞춥니다.
`hotkey` 모드로 테스트하며 하나씩 맞추면 됩니다.

### (a) 최신 메시지 우클릭 위치 — `MsgOffsetX`, `MsgOffsetY`
- 채팅창에서 **가장 최근 받은 말풍선**을 우클릭했을 때 메뉴가 떠야 합니다.
- 값은 "채팅창 왼쪽 아래 모서리" 기준입니다.
  - `MsgOffsetX` = 왼쪽에서 오른쪽으로 (말풍선 안쪽으로 들어가게)
  - `MsgOffsetY` = 아래(입력창 위)에서 위로 (최신 말풍선 높이만큼)
- AutoHotkey 설치 시 함께 오는 **Window Spy** 로 실제 픽셀을 확인하면 편합니다.

### (b) "전달" 메뉴 위치 — `ForwardMenuDownCount`
- 말풍선 우클릭 후 뜨는 메뉴에서 **`전달`** 항목이 위에서 몇 번째인지 확인.
- 메뉴 맨 위에서 `전달` 까지 **방향키 Down 을 몇 번** 눌러야 하는지를 이 값에 넣습니다.
  (예: 메뉴가 `복사 / 전달 / ...` 이면 Down 1회 → `1`)
- 잘 안 맞으면, 메뉴에서 `전달` 글자에 밑줄 있는 단축키가 있는지 보고 알려주세요.
  그 방식으로 바꿔드릴 수 있습니다.

### (c) 전달 대화상자 — `PickFirstResultX/Y`, `ConfirmBtnX/Y`
- `전달` 을 누르면 **대상 선택 대화상자**가 뜹니다. 보통 검색창에 자동 포커스됩니다.
- 스크립트가 `TargetName` 을 입력 → 검색 결과가 뜸.
  - `PickFirstResultX/Y` = **첫 번째 검색 결과(대상)** 를 클릭할 위치
    (대화상자 왼쪽 위 기준).
  - `ConfirmBtnX/Y` = **확인/전송 버튼** 위치 (대화상자 **오른쪽 아래** 기준, 음수).
- 값을 조금씩 바꿔가며 `Ctrl+Alt+F` 로 테스트하세요.

### (d) 타이밍 — `StepDelay`, `DialogWait`
- PC/카톡이 느려 단계가 엇나가면 이 값들을 늘리세요(예: 350→600).

---

## 4. 사용법

1. `AutoForward.ahk` 더블클릭 → 실행 (트레이에 아이콘 생김).
2. **hotkey 모드**: 전달하고 싶은 메시지가 있는 **채팅창을 활성화**한 뒤
   `Ctrl+Alt+F`. → 최신 메시지가 `TargetName` 에게 전달됩니다.
3. **auto 모드**: `Ctrl+Alt+A` 로 자동 On.
   새 메시지 알림 팝업이 뜨면 자동으로 열어 전달합니다.
   - ⚠️ auto 모드는 카카오톡 **설정 → 알림 → '미리보기 팝업 알림'** 이 켜져 있어야 합니다.
4. 종료: `Ctrl+Alt+Q` 또는 트레이 아이콘 우클릭 → 종료.

---

## 5. 오픈채팅 제외

두 겹으로 막습니다.

1. **스크립트**: 채팅방/창 제목이 `ExcludeTitlePatterns`(기본 `오픈채팅`) 에
   걸리면 전달하지 않습니다. 특정 오픈채팅 방 이름을 배열에 추가하세요.
2. **가장 확실한 방법**: 카카오톡에서 각 **오픈채팅방 알림을 꺼두면**,
   auto 모드가 그 방의 팝업을 아예 감지하지 못해 전달되지 않습니다.

---

## 6. 한계 / 주의

- **완전 무인 100% 안정**은 어렵습니다. 카톡 업데이트로 UI가 바뀌면 재보정 필요.
- 연속으로 여러 메시지가 몰려오면 auto 모드가 최신 것 위주로 처리하며,
  놓치는 경우가 생길 수 있습니다.
- 전달 중에는 마우스/키보드를 건드리지 마세요(자동 조작과 충돌).
- 동명이인이 있으면 검색 첫 결과가 선택됩니다. `TargetName` 을 더 구체적으로.

---

## 7. 문제 생기면

- "전달 대화상자를 찾지 못했습니다" → `DialogWait` 늘리기, `ForwardMenuDownCount` 확인.
- 엉뚱한 곳 클릭 → `MsgOffsetX/Y`, `PickFirstResultX/Y`, `ConfirmBtnX/Y` 재보정.
- 안 되면 **본인 카톡 버전 / 화면 해상도 / 우클릭 메뉴 항목 순서**를 알려주세요.
  그 값에 맞춰 좌표/단계를 조정해 드립니다.
